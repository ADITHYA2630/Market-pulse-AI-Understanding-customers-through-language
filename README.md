# 📊 Market Pulse AI
## Understanding Customers Through Language

Market Pulse AI is an AI-powered customer feedback analysis application designed to help businesses understand customer opinions from natural language.

The application analyzes customer reviews and feedback to identify **sentiment, emotions, and prediction confidence**, helping convert unstructured customer language into useful business insights.

🌐 **Live Demo:** https://keen-customer-lens.lovable.app/

📂 **GitHub Repository:** https://github.com/ADITHYA2630/Market-pulse-AI-Understanding-customers-through-language

---

## 📌 Project Overview

Customer feedback contains valuable information about customer satisfaction, expectations, and problems. However, manually analyzing large amounts of feedback can be time-consuming.

Market Pulse AI provides an interactive platform where users can submit customer feedback and receive an automated analysis.

The system is designed to answer questions such as:

- Is the customer satisfied or dissatisfied?
- What emotion is expressed in the feedback?
- How confident is the prediction?
- What can the business learn from the feedback?

---

## 🎯 Objectives

The main objectives of this project are:

1. Analyze customer feedback automatically.
2. Identify the sentiment expressed in customer language.
3. Detect emotions present in customer feedback.
4. Provide confidence scores for predictions.
5. Support analysis of multiple reviews using CSV input.
6. Convert unstructured customer feedback into understandable insights.
7. Provide a simple and accessible web interface.

---

## ✨ Key Features

### 📝 Single Review Analysis

Users can enter individual customer feedback and receive an automated analysis.

### 😊 Sentiment Analysis

Customer feedback can be categorized into:

- Positive
- Neutral
- Negative

### ❤️ Emotion Analysis

The application identifies the primary emotion expressed in the customer's feedback.

### 📊 Confidence Score

The system displays a confidence score associated with the prediction.

### 📁 CSV Batch Analysis

Users can upload customer feedback in CSV format and analyze multiple reviews.

### 💡 Customer Insights

The analysis helps users understand customer satisfaction and identify potential areas for improvement.

### 🌐 Web-Based Interface

The application provides a simple interface that can be accessed through a web browser.
